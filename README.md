# 小和 · 个人作品集

一个使用原生 HTML / CSS / JavaScript 构建的个人作品集网站，用于展示项目作品、个人介绍与联系方式。页面支持桌面端与移动端、深浅色主题切换，并带有轻量的滚动渐显动画。

## 功能特性

- 响应式布局：桌面端左侧固定边栏，移动端顶栏 + 抽屉导航
- 项目作品展示：由 JavaScript 根据数据动态渲染，后续新增项目只需修改数据数组
- 深浅色主题切换：支持一键切换，并用 localStorage 记住用户上次选择
- 滚动渐显动画：内容进入视口时柔和淡入上浮，配合项目卡片依次错开
- 导航滚动高亮：滚动页面时自动高亮当前所在区块
- 移动端抽屉导航：折叠式菜单，点击链接后自动收起

## 技术栈

- HTML
- CSS（使用 CSS 变量管理主题配色）
- JavaScript（原生，无第三方框架与组件库）

## 运行方式

本项目为纯静态页面，无需安装依赖或构建。

方式一：直接用浏览器打开 `index.html`。

方式二：在项目目录启动一个本地静态服务器（推荐，可避免部分浏览器的 file:// 限制）：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 主要功能说明

### 新增项目

编辑 `js/main.js` 中的 `PROJECTS` 数组，追加一条记录即可，页面会自动渲染，无需改动 HTML 或 CSS：

```js
{
  name: "项目名称",
  desc: "项目简介",
  tech: ["技术1", "技术2"],
  date: "2026.01",
  category: "分类",
  image: "图片地址",
}
```
